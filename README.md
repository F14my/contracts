# Лабораторная работа №2

---
Проект реализует модель `Task` с валидацией атрибутов, управлением состояниями и вычисляемыми свойствами с использованием дескрипторов Python.

### Основные возможности

- **Валидация через дескрипторы**: проверка типов, диапазонов значений и форматов данных
- **Управление состояниями**: переходы статуса задачи следуют предопределённым правилам (PENDING -> IN_PROGRESS -> DONE)
- **Неизменяемые атрибуты**: защита критических полей после инициализации объекта
- **Разделение публичного API**: чёткое разграничение интерфейса и внутреннего состояния

### Реализованные дескрипторы

#### IdDescriptor (Data)
```python
class IdDescriptor:
    """Валидация и защита идентификатора задачи"""
    # - Должен быть неотрицательным целым числом
    # - Неизменяем после первоначальной установки
```

#### ValidatedString (Data)
```python
class ValidatedString:
    """Валидация строковых атрибутов с ограничением длины"""
    def __init__(self, min_length: int = 1, max_length: int = None): ...
    # - Проверка типа (должна быть str)
    # - Валидация длины в диапазоне [min_length, max_length]
```

#### PriorityDescriptor (Data)
```python
class PriorityDescriptor:
    """Валидация приоритета в диапазоне [1, 10]"""
    # - Проверка типа (должен быть int)
    # - Валидация диапазона: 1 <= value <= 10
```

#### LazyComputedProperty (Non-Data)
```python
class LazyComputedProperty:
    """Вычисление значения свойства при каждом обращении"""
    # - Отсутствует метод __set__, т.е non-data дескриптор
    # - Используется для свойств: is_ready, is_high_priority
```

### Переходы состояний

```
PENDING       -> IN_PROGRESS, CANCELLED
IN_PROGRESS   -> DONE, CANCELLED
DONE          -> (конечное состояние)
CANCELLED     -> (конечное состояние)
```

Недопустимые переходы вызывают `TaskInvalidStateError`.

### Вычисляемые свойства

- is_ready если status == PENDING и priority >= 5
- is_hight_priority если priority >= 8
- is_critical если priority == 10


## Исключения

```
TaskError (базовое)
├── InvalidAttributeError
│   └── Выбрасывается при ошибке валидации атрибута
│       - Несоответствие типа
│       - Значение вне диапазона
│       - Нарушение формата
└── TaskInvalidStateError
    └── Выбрасывается при нарушении инвариантов объекта
        - Недопустимый переход состояния
        - Попытка изменить неизменяемый атрибут
        - Нарушение бизнес-логики
```
